# 水・空気プリセットとCSV物性表

材料画面でプリセットを選び、「選択中の材料へ適用」または「新しい材料として追加」を使う。適用時は材料IDを保持するため、その材料を参照している流体・固体の設定も同じ物性を使う。追加時は別IDの材料として登録し、流体材料として選択する。保存済みプロジェクトや実行条件を自動で置き換える処理は行わない。

| プリセット | 条件 | 温度点 |
|---|---|---|
| 水：温度依存 | 液体、101325 Pa | 5～95 °C、5 °C間隔 |
| 水：20 °C 定数 | 20 °C、101325 Pa | 4物性を定数として使用 |
| 乾燥空気：温度依存 | 乾燥空気、101325 Pa | −50～300 °C、10 °C間隔 |
| 乾燥空気：20 °C 定数 | 20 °C、101325 Pa | 4物性を定数として使用 |

密度[kg/m³]、動的粘度[Pa·s]、定圧比熱[J/(kg·K)]、熱伝導率[W/(m·K)]を含む。温度表は既存ソルバーの線形補間を使用し、範囲外は端点値で固定する。圧力依存・湿度・相変化を表すものではない。現行の流れモデルは非圧縮近似で、流れの密度は初期温度の基準値、温度依存密度は熱計算の蓄熱・拡散係数に使われる。

値は **CoolProp 7.2.0 / HEOS** により上記の温度・圧力で生成した。[水の式と文献](https://coolprop.org/fluid_properties/fluids/Water.html)、[空気の式と文献](https://coolprop.org/fluid_properties/fluids/Air.html)、[SI API](https://coolprop.org/coolprop/HighLevelAPI.html)を参照。生成スクリプトは `scripts/generate_material_presets.py`、配布データは `workbench/data/material_presets.json`。ライブラリ版とGit revisionをデータに記録する。CoolPropは開発時の再生成にのみ必要で、アプリ実行時やDocker起動時に外部接続・追加インストールは不要。

## CSV形式

UTF-8（BOM付きも可）、カンマ区切り、ヘッダー必須。最大1 MiB、データ2～10000行。温度列は `temperature_K` または `temperature_C` を明示する。℃は読み込み時にKへ変換する。

複数物性を読み込む場合（必要な物性列だけでもよい）:

```csv
temperature_C,density,viscosity,heat_capacity,conductivity
20,998.2,0.001002,4184,0.5980
40,992.2,0.000653,4179,0.6285
```

各物性カードから1物性だけ読み込む場合:

```csv
temperature_K,value
293.15,0.001002
313.15,0.000653
```

`value` は選択した物性のSI単位。粘度は動粘度[m²/s]ではなく粘性係数[Pa·s]を入力する。全体のCSV読み込みでは曖昧な `value` 列を使わず、物性名を指定する。

複数物性形式では単位付きヘッダーも使える。例えば `viscosity_mPa_s` または `viscosity_cP` はPa·sへ、`heat_capacity_kJ_kg_K` はJ/(kg·K)へ変換する。単位なしの物性名と2列形式の `value` は常にSI単位。認識可能な別名は `workbench/material_csv.py` 冒頭の表に限定し、未知の単位は推測せずエラーにする。

読み込み後、列・行数・温度範囲・先頭行をプレビューして適用する。含まれている物性だけを置換し、他の物性は保持する。温度順が逆の場合は昇順に並べ替えた旨を通知する。温度重複、空欄、不明な列、非数・無限大、ゼロ以下の物性、絶対零度以下の温度、列数違いは受け付けず、元の材料は変更しない。指数表記・引用符・CRLF改行・空行に対応する。

画面からテンプレートをダウンロードできる。配布ファイル:

- `static/examples/material-properties.csv`: 水の複数物性を含む短い例
- `static/examples/material-property.csv`: 粘度の2列例
- `static/examples/water-temperature.csv`: 水のプリセット全点
- `static/examples/air-temperature.csv`: 空気のプリセット全点

プロジェクト保存・ZIP書き出しでは読み込んだ数値そのものを保存するので、移行先に元のCSVファイルがなくても使用できる。
