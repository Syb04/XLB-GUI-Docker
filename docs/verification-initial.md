- このPCにはDocker Engine / Docker Desktopがないため、**Dockerイメージのビルド・起動は未確認**。Dockerfile、Compose、GPU用オーバーライドを用意し、Gmshに必要だった `libGLU` と `libXft` をイメージの依存にも反映しました。
- CUDA対応JAXが既存WSL環境にないため、**GPU計算は未確認**。GPU用イメージではCUDA対応JAXを追加します。
- 任意形状における流れ・熱の工学精度、格子収束、長時間安定性、乱流精度は未受理。旧円管ソルバーの検証値は引き継いでいません。
- 流れは基準密度を使う非圧縮近似、熱は陽的な移流拡散です。密度の温度依存は熱の蓄熱・拡散係数に使用し、浮力や熱膨張には使用しません。
- このバージョンのCAD壁はボクセル壁です。個々の曲面パッチを指定する境界、共役熱伝達、乱流モデル等の範囲はREADMEを参照してください。
