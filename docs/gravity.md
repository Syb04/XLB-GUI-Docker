# 重力と温度差による浮力

モデルツリーの「物理モデル」で「重力を有効化」を選びます。重力加速度は XYZ の SI 単位（m/s²）で指定します。標準値 `[0, 0, -9.80665]` は −Z 方向です。既存プロジェクトは有効にするまで従来どおり計算します。

## モードの使い分け

- **重力（一定加速度）**: 流体に `a = g` を適用します。重力による静水圧を含むゲージ圧を表示します。密閉された定密度流体では、重力と圧力勾配が釣り合い、定常状態で流速はほぼゼロになります。
- **浮力（温度依存密度）**: `a = [ρ(T)/ρ(Tref) − 1] g` を適用します。基準静水圧を差し引いた圧力を扱い、温度による密度差が流れを駆動します。基準温度 Tref は K で指定します。水・空気の温度依存プリセット、CSV、手入力の密度テーブルを使えます。定密度材料の浮力はゼロです。

自然対流には後者を選び、熱計算と温度依存密度を有効にして、温度境界や発熱を設定してください。熱計算が無効なら、温度は初期値のままです。固体には流体の重力項を適用しません。共役熱伝達による流体の温度変化は浮力に反映します。

浮力モードの圧力境界にも、基準静水圧を差し引いた値を入力します。通常の静水圧成分は `ρref g·(x − xref)` なので、物理圧力が必要なら指定した基準位置・基準圧力に対してこの成分を加えてください。結果画面には保存済み実行の圧力の意味を表示します。

## 計算法と制約

D3Q27 BGK に Guo の外力離散化を追加しました。分布関数から求める速度には半ステップ補正 `u = Σcf/ρ + aΔt/2` を適用し、初期値・速度境界・再開時も同じ定義を使います。熱更新で浮力が変わった場合も、指定した境界速度を維持します。

浮力は基準密度を使う非圧縮近似です。流体セルの `|ρ(T)/ρref − 1|` が 10% を超える場合はエラーで停止します。温度依存物性のテーブル外は既存の仕様どおり端点固定です。圧縮性流れ、自由表面、多相流、重力による固体変形を扱う機能ではありません。

時間刻みの推奨表示には、従来の境界速度による CFL・マッハ数制約に加え、格子速度増分 `|a|Δt²/Δx ≤ 0.05` と重力による格子密度差の見積もり `3 Σ|aᵢ|Lᵢ(Δt/Δx)² ≤ 0.1` を使います。浮力の事前見積もりは密度差 10% を仮定するため保守的です。実行時は現在の密度差で検査します。推奨値は熱拡散や緩和時間、発達後の流速に対する安定性を保証しません。

極低速の流れでは外力の有無だけでなく、浮力と粘性・慣性の比、格子解像度、時間刻み、丸め誤差が重要です。本実装の流体分布関数は FP32 です。微小速度の定量評価には格子・時間刻み依存性と物理ベンチマークによる確認が必要です。

## CPU・GPU・RAMと保存

CPU、通常の CUDA、GPU＋RAM の全経路に対応します。通常の CUDA では温度からの浮力計算も GPU 上で行い、検査用スカラーのみ取得します。GPU＋RAM では加速度を RAM に置き、衝突バッチごとに 3 成分の FP32 を追加転送します（12 bytes/cell/step）。加速度場・外力演算の一時配列ぶん、重力無効時よりメモリが増えます。

結果スナップショットとリスタートに対応します。途中で重力のモデル・方向・大きさ・基準温度を変更した継続計算は受け付けず、新規実行が必要です。重力を無効にした旧形式のチェックポイント互換性は維持します。
