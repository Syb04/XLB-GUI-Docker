# 残差モニター

画面下部の「残差モニター」または結果設定のモニターボタンから、計算中の速度・圧力・温度の履歴を確認できます。「スタディ」で許容値と必要な連続サンプル数を指定します。初期値は相対変化 `1e-5` 以下を連続 5 点です。出力間隔が記録間隔で、場のスナップショット保存間隔とは独立しています。

## 見方

色分けした対数グラフが下がり、すべての有効な場が破線の許容値以下を指定回数連続して満たすと、定常性の基準を満たした表示になります。速度だけでなく、圧力と温度が引き続き変化していないか確認してください。実単位の最大変化量（m/s、Pa、K）も併記します。

初期点には比較対象がないため数値を表示せず、収束判定にも数えません。無効な物理場は判定から除外します。ゼロは対数軸に直接描けないためグラフの下端に表示し、数値は 0 のままです。計算終了・停止時の短い記録区間は、通常区間より変化が小さくなるため連続判定には使わず、連続カウントをリセットします。

この値は **前回記録した場からの時間変化による定常性の目安** です。XLB の陽的な LBM 更新には、Fluent の圧力補正式や COMSOL の Newton 法と同じ反復方程式が存在するわけではなく、本機能はそれらの代数残差を出力するものではありません。定常性の基準を満たしても、離散化誤差や境界条件の妥当性まで保証されません。

過渡流れ・自然対流の振動・LESでは、正しい物理解でも変動が続く場合があります。また、小さな時間刻みや記録間隔は変化量を小さくします。物理時間に対する履歴、速度や温度の実単位の変化、結果の分布と併せて判断してください。記録周期と同じ周期の変動は見逃す可能性があるため、疑わしい場合は記録間隔を変えて確認します。モニターによる自動停止は行いません。

## 定義

現在の記録を n、直前を m とし、すべて SI 単位で計算します。

| 場 | 分子（最大変化量） | 正規化の分母 |
| --- | --- | --- |
| 速度 | 流体セルでの `max ‖uⁿ − uᵐ‖₂` | 現在・前回の最大速さと `1e-6 m/s` の最大値 |
| 圧力 | 流体セルでの `max |pⁿ − pᵐ|` | 現在・前回の最大絶対圧力と `1 Pa` の最大値 |
| 温度 | 流体・CHT固体での `max |Tⁿ − Tᵐ|` | 現在・前回の `max |T − Tinitial|` と `1 K` の最大値 |

圧力は保存結果と同じゲージ圧、浮力モードでは基準静水圧を除いた圧力です。大きな圧力基準値は相対変化を小さくするため、Pa の最大変化量も確認してください。温度は絶対温度そのものでは正規化しません。床値はゼロ除算を防ぎ、微小な場の実単位の変化を評価するためのものです。

GPU上では倍精度の集計を実行し、記録ごとに6個の集計値を取得します。流体分布関数自体の精度は従来どおりFP32です。比較用の前回の速度・温度・密度は各計算デバイスに保持します。従来の監視に対し、密度場1組の保持と集計演算が追加されます。GPU＋RAMでは集計をCPUで行います。

## 保存と再開

全記録を `history.csv` に逐次保存します。計算中やエラー停止後も、そこまでの記録を取得できます。画面用の実行状態は直近 2000 点まで保持し、長時間計算でも履歴のメモリが増え続けないようにしています。

閾値は実行時の入力に保存し、表示中の過去の判定が現在の編集設定で変わることはありません。リスタートはチェックポイントを新しい比較開始点とし、連続カウントを引き継ぎません。記録時刻は元の実行からの累積時刻です。監視設定の変更は物理的な再開互換性を壊しませんが、GUIからの再開は従来どおり元実行の入力を再利用します。

旧実行のCSVは従来の合成残差として表示します。旧値の温度正規化・収束判定は異なるため、新モニターの値と直接比較しないでください。
